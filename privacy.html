プライバシーポリシー

最終更新：2026年9月22日

KAZUMIYA（以下「当社」）は、提供する各種サービス（以下「本サービス」）において、お客様の個人情報の取り扱いについて以下のとおり定めます。

1. 収集する情報

本サービスの利用にあたり、以下の情報を収集することがあります。

  • 氏名・メールアドレスなどのアカウント情報
  • Googleアカウント情報（OAuth認証経由）
  • ライセンスキー・決済に関する情報（クレジットカード番号は当社サーバーに保存しません）
  • サービス利用に関するログ情報
  • お問い合わせ内容

2. 利用目的

収集した情報は以下の目的で利用します。

  • 本サービスの提供・運営・改善
  • ライセンスキーの発行・管理
  • お支払いの処理・請求
  • お問い合わせへの対応
  • 重要なお知らせ・サービス変更の通知
  • 不正利用の防止

3. 第三者への提供

当社は、以下の場合を除き、お客様の個人情報を第三者に提供しません。

  • お客様の同意がある場合
  • 法令に基づく場合
  • 人の生命・身体・財産の保護のために必要な場合

4. 業務委託先への開示

サービス運営のため、以下の外部サービスを利用しています。各サービスのプライバシーポリシーに基づき情報が取り扱われます。

  • Google（Firebase / Google OAuth）
  • Stripe（決済処理）
  • Vercel（ホスティング）
  • Anthropic（AI処理）
  • Resend（メール送信）

4-2. Google APIから取得するデータの取り扱い（MEO Manager PRO for Hotels / for Shops）

MEO Manager PRO for Hotels（https://meo.kazumiya-ai.com）および MEO Manager PRO for Shops（https://shop.kazumiya-ai.com）は、お客様の許可を得て Google Business Profile API を利用します（スコープ：business.manage、およびログインのための氏名・メールアドレス）。

  • 取得する情報：お客様が管理するビジネスプロフィールの店舗・施設情報、口コミとその返信、投稿、表示回数などの成果データ、Googleアカウントの氏名・メールアドレス
  • 利用目的：口コミへの返信の作成と投稿、Googleへの投稿の作成と公開、成果の集計とレポートの作成など、本サービスの機能の提供のみ
  • 保存：口コミへの自動返信や予約投稿を行うため、ログイン情報（リフレッシュトークン）を暗号化して保存します。アプリの「Googleアカウント連携」を解除するか、ご解約後のご依頼により削除します。Googleアカウントの「サードパーティ製のアプリとサービス」からも、いつでもアクセスを取り消せます
  • 共有：返信文・投稿文の作成のため、口コミ本文などを業務委託先のAI（Anthropic）に送信します。それ以外の第三者への提供、販売、広告目的での利用、AIモデルの学習への利用は行いません

Google APIから取得した情報の使用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。

5. Cookieの利用

本サービスは、セッション管理のためにCookieを使用します。ブラウザの設定によりCookieを無効にすることができますが、一部機能が利用できなくなる場合があります。

6. 個人情報の管理

当社は、お客様の個人情報を適切に管理し、不正アクセス・紛失・破壊・改ざん・漏洩などを防止するための合理的な安全対策を講じます。

7. 開示・訂正・削除

お客様は、ご自身の個人情報の開示・訂正・削除を求めることができます。ご希望の場合は info@kazumiya-ai.com までご連絡ください。

8. 未成年者の利用

本サービスは、18歳未満の方のご利用を想定していません。未成年者が本サービスを利用する場合は、保護者の同意が必要です。

9. ポリシーの変更

当社は、必要に応じて本ポリシーを変更することがあります。重要な変更がある場合は、本ページにて通知します。
